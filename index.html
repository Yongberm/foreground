2차 수정 안내검수 서버에서 보이는 것과 그 이유 · 2026-10-02 기준

A. 서버 · API 설정 때문인 것

게임 코드가 아니라 API 에서 내려주는 값으로 정해지는 것입니다.

보이는 것이유고칠 곳
모든 게임이 한 판 2분 검수 API 가 9개 레벨 모두 play_time 120초를 보냅니다. 게임은 API 값을 먼저 쓰고, 값이 없을 때만 기본값(워드매치 40초, 블록 단어 · 실로폰 단어 180초, Star word · 터치 단어 · 워드 파이프 210초)을 씁니다. API play_time
시간이 남았는데 단어가 없어 게임이 끝남 블록 단어(7문제) · 실로폰 단어(10) · Star word(10) · 터치 단어(12) · 워드 파이프(12)는 정해진 문제를 다 풀면 결과로 가는 규칙입니다. 한 판 시간이 길어 시간이 남습니다. Star word LV1(6문제) · LV2(8문제)는 미로 칸에 놓을 수 있는 단어가 적어 문제가 더 적습니다. API play_time
랭킹 1위 · 내 최고 점수가 볼 때마다 다름 같은 요청을 연달아 보내도 검수 랭킹 응답이 매번 다르게 옵니다. 게임은 받은 목록을 그대로 그립니다. 검수 랭킹 서버
아주 긴 뜻(70~87자)의 글자가 작음 서버가 내려준 단어를 빼지 않고 칸에 맞게 줄여 넣기로 해서, 가장 긴 뜻은 20px 안팎까지 작아집니다. API 뜻 문구
도움말에 기호가 글자 그대로 보임 \n · &amp; 처럼 알아볼 수 있는 기호는 풀어서 보여 주고, 잘못된 코드는 고쳐 쓰지 않고 그대로 둡니다. API 도움말 문구

B. 게임마다 다르게 둔 것

보이는 것이유
결과 화면 점수 밑 문구가 게임마다 다름 카드 짝 맞추기는 "점수와 순위를 저장했습니다."로 고정해 Ranking 을 눌러도 바꾸지 않습니다(두더지 잡기도 바뀌지 않음). OX 퀴즈 · 축구 · 바다속 단어 · 레이싱은 Ranking 을 열면 "…님의 최고 점수는 …"으로 바뀌는 지금 동작 그대로입니다. 스펠링 게임은 랭킹이 없습니다.
시간이 남았는데 끝나는 게임 문제 수 규칙은 그대로 두고, 한 판 시간은 API 로 맞추기로 했습니다(위 A 두 번째 줄).
