획 가이드 편집기

점이나 번호를 눌러 고르고 ←→↑↓ 로 1px씩 옮긴다 (Shift 10px). 끌어서 옮겨도 된다. 선을 더블클릭하면 점 추가, Alt+클릭 또는 Delete 는 점 삭제, Tab 은 다음 점, Esc 는 선택 해제. Ctrl+휠 또는 +− 로 확대(0 맞춤), 휠·빈 곳 끌기로 이동. 확대하면 가장자리에 좌표 눈금과 미니맵이 뜬다. 고친 값은 브라우저에 남는다.
